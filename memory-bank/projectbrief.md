# Project Brief

## Project Overview
This is a NestJS-based backend application project for training and learning purposes. The project is currently in its initial setup phase with only a `.gitignore` file present.

## Core Requirements
- **Framework**: NestJS (Node.js backend framework)
- **Purpose**: Training/learning project for backend development
- **Architecture**: Modular, layered architecture with feature-based modules
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT-based authentication
- **API Design**: RESTful APIs with consistent response format

## Required Features
1. **Environment Configuration**: Manage environment variables through validated class with direct property access (envConfig.PROPERTY)
2. **Logging**: Dual logging system - logs written BY developers (manual) and logs written BY system (automatic) with multiple transports and sensitive data protection
3. **Request Validation**: Input validation using class-validator
4. **MongoDB Connection**: Database connection with Mongoose
5. **Middleware**: Custom middleware implementation
6. **Interceptors**: Response transformation and logging
7. **Cron Jobs**: Scheduled task execution
8. **Code Formatting**: ESLint, Prettier, and Husky setup
9. **Response Consistency**: Standardized API response format

## Project Goals
1. **Learning**: Master NestJS framework and best practices
2. **Architecture**: Implement clean, scalable backend architecture
3. **Best Practices**: Follow NestJS conventions and TypeScript best practices
4. **Documentation**: Maintain comprehensive documentation throughout development

## Key Constraints
- Must use TypeScript
- Must follow NestJS conventions
- Must be production-ready architecture (even for learning)
- Must include proper error handling and validation
- Must include testing strategy

## Success Criteria
- Clean, maintainable codebase
- Proper separation of concerns
- Comprehensive documentation
- Working API endpoints
- Proper error handling
- Testing coverage
